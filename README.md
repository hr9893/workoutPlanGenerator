# 🏋️ AI Workout Planner

An interactive web application built with **Python** and **Streamlit** that generates personalized fitness routines based on your weekly availability, fitness goals, and preferences.

---

## 🌟 Key Features

* **Customized Schedules:** Tailors workout splits to your available days (e.g., 3-day full body, 4-day upper/lower, 5-day push/pull/legs).
* **Goal-Oriented Plans:** Optimizes exercises for Muscle Gain (Hypertrophy), Fat Loss, Strength, or General Fitness.
* **Flexible Parameters:** Accounts for available equipment (Gym, Dumbbells, Bodyweight) and experience level.
* **Instant Plan Generation:** Clear, organized table outputs with sets, reps, and target muscle groups.

---

## 🛠️ Tech Stack

* **Language:** Python 3.9+
* **Framework:** [Streamlit](https://streamlit.io/)
* **Data Handling:** Pandas
